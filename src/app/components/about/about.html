About Me

I am a versatile engineer and analyst passionate about turning raw data into actionable software solutions.

By combining the analytical mindset of a Data Analyst with the architectural rigor of a Software Engineer, I build systems that are both scalable and insightful. My journey bridges multiple disciplines:

  • Software Engineering: Building robust, user-centric web applications and scalable backends.
  • Data Engineering: Designing robust data pipelines, managing databases, and ensuring high data integrity.
  • Data Analysis: Extracting business value, visualizing trends, and communicating insights effectively to stakeholders.

I believe that good software is built on clean data, and good data is useless without intuitive software to deliver it. I focus on writing maintainable code, automating the mundane, and building tools that empower users.

When I'm not optimizing SQL queries or crafting UIs, you can usually find me reading about emerging tech trends or exploring the outdoors.
